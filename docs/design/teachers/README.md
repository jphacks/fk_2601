# 先生用 管理画面のデザイン見本（黒板案）

学校の先生が使う管理画面（`docs/06-school-expansion.md` 5章）の見た目の見本です。**アプリのコードではありません。**
アプリ（Next.js + Tailwind CSS）で先生の画面を作るときに、見た目と動きをそろえるための参照として使ってください。
子どもの画面の見本（`docs/design/`）とは別のものです。色の名前も別にしてあります（すべて `t-` 付き）。
**この見本は画面の構成まで考えて作ったものです。見本にある画面・機能・動きは、実装するものとして扱います**（下の「見本の決まりごと（仮のもの）」にある仮の値と【未決】、見本の中だけで使う絵は除きます）。仕様の文章は `docs/06-school-expansion.md` 5章にあります。

## 見かた
- `index.html` をブラウザで開くと、全画面が一覧で見られます（Google Fonts を読むのでネット接続が必要）
- 各画面は `screens/` に1枚ずつあります。大きさは 1440×900（教室に映す画面と参加コードを映す画面は 1600×900）です
- 一部のボタンでは画面を行き来できます：上のメニュー、はてなのタブ、教室に映すの「つぎへ・もどる」と「映す先」、設定のタブ、参加コードの「教室に大きく映す」、「クラスから外す」の確認
- 入力・確認ボタン・しぼりこみなどは、見本では動きません。動きは下の「画面のうごき」に書いてあります
- ナビの絵は子どもの見本と同じ `../assets/navi/` を使います。**`docs/design/teachers/` に置いたまま開いてください**（ほかの場所ではナビの絵が出ません）

## コンセプト：黒板案
1. **1画面に全体が入る**：1440×900 で、ページ全体はスクロールしない。中身が多いときは、パネルの中だけスクロールする。幅 1100px より狭いと、パネルを縦に並べてふつうのスクロールにもどす
2. **開いたら、まず「やること」**：参加の確認と、あしたのミッションを、きょうの画面のその場で片付けられる
3. **いま何が見えるかを、いつも出す**：ヘッダーに「授業時間中 〜15:30・内容まで見えます」／「授業時間の外・件数だけ数えます」を出す（5.2）
4. **子どもの はてなを授業の材料にする**：クラスに共有された はてなを、教室のモニターや黒板に映して、みんなで予想して答え合わせする
5. **比べない**：順位、人ごとの件数の並び、予想の当たり外れの割合は出さない（5.5）。メンバーの一覧にも件数は出さない

## 文字
| 用途 | フォント | 大きさの目安 |
|---|---|---|
| 先生の画面すべて | BIZ UDPゴシック 400/700（`font-t-body`） | 見出し 22px・パネルの見出し 16px・本文 13〜14px・説明 12px・大きな数 24〜30px |
| 教室に映す（モニター） | Klee One 600（`font-t-chalk`） | 問い 64px・答え 156px・説明 32px |
| 教室に映す（黒板に投影） | Zen Maru Gothic 900（`font-t-cast`） | モニターと同じ大きさ。太い字で、光が弱くても読めるようにする |

- 数は `font-variant-numeric: tabular-nums`（桁がそろう）

## 形とレイアウト
| 部品 | 形 |
|---|---|
| カード | 白・1px の `t-line`・角丸 14px（`rounded-tcard`）。影はつけない |
| メインボタン | `t-board` の地に白い文字・角丸 8px（`rounded-tbtn`）・高さ 36〜40px |
| サブボタン | 白い地に `t-board` の線と文字 |
| 文字だけのボタン | 地も線もなし・`t-board` の太字（「ちがう」「変える」など） |
| 消すボタン | 白い地に `t-danger-line` の線と `t-danger` の文字。確認のダイアログの中だけ `t-danger` の地 |
| 数のタイル | `t-ground` の地・角丸 10px・小さい説明＋大きな数 |
| ピル（状態） | 高さ 22〜24px・角丸いっぱい（「きょう」「予定」「まだ」「祝日」など） |

- タブレットで使うときは、押せるものの高さを 44px 以上にする（見本は PC 向けに 36〜40px。`pointer-coarse:h-11`）
- 角丸のクラスは `rounded-tcard`・`rounded-tbtn`。`rounded-t-card` と書くと、Tailwind の「上の角だけ丸める」と子どもの画面の `--radius-card` にも当たり、上の角だけ 24px になる
- 外わくは `height: 100vh`、パネルは `min-height: 0; overflow: auto`。グリッドの中でカードがつぶれないよう、`grid-auto-rows: max-content` を付ける
- 1100px より狭いときは、パネルを1列にして、ページのスクロールにもどす

## 画面のうごき（見本では動かないもの）
- **きょう**：「確認」でその子が一覧から消え、確認待ちが0人になると「全員の確認がおわりました」。ミッションは文を入れると「出す」が押せて、出すと子どもの画面の見え方に変わる（「変える」で戻る）。やることの数は、残っているものの数
- **ミッションの文**：漢字が入ると注意を出す（出すことはできる）。30字をこえると数と枠を `t-danger` にして、出せなくする。クラスを1つも選ばないと出せない。2クラス選ぶとボタンが「2クラスに出す」になる
- **ミッション**：今週の行のうち、これからの日だけ選べる。選ぶと右で編集できる。「この日は出さない」で取り消せる
- **はてな**：分野と単元でしぼる。単元を選ぶと右に その単元だけ出る。「クラスから外す」は確認のダイアログを出す。「教室に映す」は、共有された はてなにだけ出す
- **教室に映す**：はてな → よそう → しょうたい の3段階。下の段階の丸でも進める。「映す先」でモニターと黒板を切り替える（どちらで映したかは先生ごとに覚えておくとよい）。答えは「しょうたいを 見せる」を押すまで出さない（8章）
- **メンバー**：左の一覧で選ぶと、右に その子の様子が出る。確認待ちは、出席番号を入れてから確認できる（あとからでもよい）
- **クラスの設定**：曜日ごとの時刻を変えると、帯がすぐ動く。曜日のチェックを外すと「授業時間に入れない」。参加コードは「受付中／受付を止めています」を切り替える
- **参加コードを映す**：「教室に大きく映す」で開く。真ん中にコードを大きく出すだけのシンプルな画面。「映す先」でモニターと黒板を切り替え（色・線・文字は教室に映す画面と同じ）、「とじる」で設定にもどる。コードは見まちがえにくいよう、BIZ UDPゴシック（太字・168px）で1行に出す

## 見本の決まりごと（仮のもの）
- 名前・ユーザー名・メールアドレス・件数・日付は、すべて見本です（2026年11月4日（水）10:40 を「いま」としている）
- 写真の部分は、切り抜き画像の代わりに描いた絵（`assets/samples/`）です
- 称号の名前（はかせの たまご など）、ミッションの文、問いと答えは見た目の確認用です
- 運営の確認にかかる日数、学校のメールアドレスのドメイン（`example.ed.jp`）：仮

## アプリへの取り込み方
1. `src/app/globals.css` で `teachers/tailwind-theme.css` を読み込む（済み）
2. フォントは `next/font/google` で読み込み、先生の画面の中だけで使う（子どもの画面を重くしない）。`BIZ_UDPGothic`（400・700）を `--font-t-body` に割り当てる（`src/app/teacher/layout.tsx` で済み）。教室に映す画面を作るときに、`Klee_One`（600）を `--font-t-chalk`、`Zen_Maru_Gothic`（700・900）を `--font-t-cast` に割り当てる
3. ナビの絵は、子どもの画面と同じ `public/navi/` のものを使う
4. 画面は見本の HTML を見ながら、上のレシピで組み立てる（インラインスタイルの値はトークンと同じ）
5. `assets/samples/` の絵はアプリに持ち込まない（本物は子どもが囲んだ切り抜き画像）

## source/ について
デザインを作った Claude のキャンバス用の元ファイルです（`{{ }}`・`sc-for`・`sc-if`・`dc-import` を使う書き方）。ブラウザでそのままは開けません。
画面ごとの状態の持ち方（どのボタンで何が変わるか）を確かめたいときに、下の `<script>` の中を読んでください。見本の HTML（`screens/`）は、これを展開して書き出したものです。
