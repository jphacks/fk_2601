# はじめまして のデザイン見本（Issue #87）

はじめて使う子どもの **登録** と **あそびかたの説明** の見た目の見本です。**アプリのコードではありません。**
`/login` と `/profile` の作り直し、あそびかたの説明を作るときに、見た目と動きをそろえるための参照として使ってください。

- 対象は `docs/06-school-expansion.md` 4章のうち、学校なしで使える部分（ログイン ID の方式）です。本名・学校のメールアドレス・クラスのコードの手順は、学校での利用がまだ構想なので入れていません
- 色・線・影・文字の決まりは、子どもの画面の見本（`docs/design/README.md`）と同じです。この README には、はじめまして だけの決まりを書きます

## 見かた
- `index.html` をブラウザで開くと、全画面が一覧で見られます（Google Fonts を読むのでネット接続が必要）
- 各画面は `screens/` に1枚ずつあります。大きさは 390×844 です
- ボタンで次の画面へ進めます。文字を消すと「つぎへ」が押せなくなり、パスワードの2回目を変えると その場で「1かいめと ちがうよ」が出ます
- 色・ナビの絵・共通の CSS は、親の `docs/design/` のもの（`../tokens.css`・`../screen.css`・`../screen.js`・`../assets/navi/`）を使います。**`docs/design/first/` に置いたまま開いてください**（ほかの場所ではナビの絵と色が出ません）
- 登録とあそびかたの外へ出るリンク（ホーム・やくそく など）は、親の見本 `docs/design/screens/` を開きます

## 流れ
```
はじめての人：ようこそ →「はじめる！」→ ① ログイン ID → ② パスワード（ここで ID を つくる）→ ③ ニックネーム → ④ 学年
              → じゅんび できたよ →「あそびかたを みる！」→ あそびかた 1/3 → 2/3 → 3/3 →「やってみる！」→ やくそく → カメラ
                                 └「とばして はじめる」→ ホーム        （どの あそびかたでも「とばす」→ ホーム）
2回目から    ：ようこそ →「つづきから」→ おかえり（ID と パスワード）→ ホーム（あそびかたは 出さない）
もういちど    ：せってい →「あそびかたを もういちど みる」→ あそびかた 1/3 から
```

## 登録の決まり
- **ナビが1画面に1つずつ聞く**：上に もどるボタンと、進み具合（バーと「1/4」）。ナビとふきだしで聞くことを大きく出し、その下に入力欄を1つだけ置く
- ナビの表情：ようこそ・ニックネーム・じゅんび できたよ＝にこにこ／ログイン ID・学年＝はてな／パスワード＝ぎゅっ（だいじな ところ）／ID が つかわれていた＝ぽかん。画面が変わるたびに、ナビが はねて出てくる（`navi-react`）
- **入れおわるまで「つぎへ」は押せない**：うすくして押せなくする（アプリの `Button` の `disabled` と同じ `opacity: 0.4`）
- もどるボタンで前の手順へ戻っても、入れたものは消さない（③ ニックネームでは もどるボタンを出さない。② で ID を もう作ったため）
- 下のボタンは、画面の下に固定する。スマホのキーボードが出ても、ボタンがキーボードの上に見えるようにする（`min-h-dvh` と、入力中に下のボタンが隠れないこと を実機で確かめる）

| 画面 | ナビのことば | 入れるもの・決まり | 下のボタン |
|---|---|---|---|
| 01 ようこそ | はじめまして！ かこって はてな!? へ ようこそ！ | アプリの名前のロゴ（「はてな」を かこむ わっか）と、ひとことの せつめい | はじめる！／つづきから（ID を もっている ひと） |
| 02 ① ログイン ID | ログイン ID を きめてね | 英数字・ひらがな・カタカナ（ひらがなは 10文字まで：`docs/02-spec.md` 4章）。「ニックネーム（よばれる なまえ）は あとで きめるよ」と書いて、なまえを2回聞いているように見えないようにする | つぎへ |
| 03 ② パスワード | パスワードを きめてね | 6文字以上。2回入れる。「みる／かくす」で2つとも切りかえる。6文字以上になったら「✓ 6もじ いじょう、OK！」、2回目が同じなら「✓ おなじだよ！」、ちがえば その場で「1かいめと ちがうよ」。わすれると戻れないので「おうちの ひとと メモしてね」 | **ID を つくる！**（ここで アカウントを作る） |
| 04 ③ ニックネーム | ニックネームを きめてね | 10文字まで（入れた数を「2/10」で出す）。「ログイン ID とは べつ」「ほんとうの なまえは いれないでね」 | つぎへ |
| 05 ④ 学年 | 学年を おしえてね | 1〜6年の大きなボタン。選ぶ前も影つき、選んだら色がつき押しこまれた形（影なし・4px 下がる：`docs/02-spec.md` 2.3）。「がくねんに あわせて、はてなの むずかしさが かわるよ」 | けってい！ |
| 06 じゅんび できたよ | じゅんび できたよ！ かこって はてなを みつけちゃおう！ | ニックネーム・学年・ログイン ID を まとめて見せ、「ID と パスワードは おうちの ひとと メモしてね」 | あそびかたを みる！／とばして はじめる |
| 12 ID が つかわれていたとき | その ID は つかわれてるよ | ② で アカウントを作れなかったとき、① に戻して出す。入れた ID を残し、同じ ID のままでは押せない。**パスワードは そのまま**（入れなおさない） | この ID で つくる！（③ へ） |
| 11 おかえり | おかえり！ まえに きめた ID で ログインしてね | ID と パスワードの1画面だけ。わすれたときは「おうちの ひとと かいた メモを みてね」（戻す方法はない） | ログイン |

- ID が つかわれているかは、作るとき（②）でないと分からない（メールアドレスで調べる方法は使えない）。そのため ② のあとで ① に戻す

## あそびかたの決まり
- **はじめての1回だけ**出す。「はじめて」は**アカウントごと**に判定する（学校の端末は共有することがあり、同じ子が別の端末を使うこともあるため：`docs/06-school-expansion.md` 4.2）
- 本物のホームを暗くして（`ink` の 74%）、その上に説明を出す。いま説明しているものだけ、暗くしない（その要素を `position: relative; z-index` で上に持ち上げる）
- 3枚。上に進み具合の点と、**どの画面でも「とばす」**（3枚目は「とじる」）。とばすと ホームへ
  1. **あそぶ じゅんばん**：さがす → かこむ → えらぶ → せーの！ → こたえあわせ → もしも → のこす の7つ。番号の丸と、ひとことの説明
  2. **下のナビ**：ナビだけ明るくして、5つ（ずかん・スタンプ・ホーム・みんな・せってい）が何をするところかを書く
  3. **はてなを さがす！**：ボタンだけ明るくして、黄色の点線で囲む。点線は、ボタンの下の影（7px）のぶん下を広くして、ボタンと影を合わせた形の まわりに同じ すきまで出す。「やってみる！」で やくそく → カメラ、「ホームを みる」で閉じる
- 説明のカードは白（暗い地の上なので線はつけない）。カードから説明しているものへ、しっぽ（三角）を向ける
- せっていに「あそびかたを もういちど みる」（押せる行）を足す。押すと 1枚目から出す
- 動き：カードは下から ふわっと出る（`sheet`）。動きを減らす設定のときは動かさない

## 「説明ずみ」の保存先（2026-11-06 に決めた）
- プロフィール（Firestore の `users/{uid}/profiles/{profileId}`）の `guideSeenAt`（説明を見おわった・とばした時刻）に持つ。いまの `firestore.rules` のまま使え、ローカル版（`NEXT_PUBLIC_BACKEND=local`）も同じ形で保存される。いまは1アカウントに1プロフィールなので、アカウントごとに一度だけ出る（はじめは `users/{uid}` に持つ案だった）
- 「とばす」「とじる」「やってみる！」「ホームを みる」「とばして はじめる」のどれでも、見おわったことにする
- くわしくは `docs/02-spec.md` 4.2・`docs/03-technical.md` 6章

## 文字
- 22px 以上の文字の漢字にはふりがな（例：④ の「学年」）、それより小さい文字は ひらがな。わかち書き（`docs/02-spec.md` 2.1）
- 本名 →「ほんとうの なまえ」（`docs/02-spec.md` 2.2）
- 画面の呼び方：ログインに使う名前は「ログイン ID」、人に見える名前は「ニックネーム」（`docs/02-spec.md` 4・5章。`docs/06-school-expansion.md` の「ユーザー名」にあたる）
