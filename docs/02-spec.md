## 2 共通の決まり
### 2.1 文字
- 学校版の管理画面（未実装）は大人向けなので、2.1・2.2 の決まりを使わない。ただし、先生が書いたミッションを子どもの画面に出すときは使う（`docs/06-school-expansion.md` 5章・5.3）
- 22px 以上の文字の漢字には、すべてふりがなを振る。それより小さい文字は、ひらがなで書く（小さい文字のふりがなは、つぶれて読めないため。`docs/design/README.md`「文字」）
- 漢字は学年の漢字配当に合わせる。学年別漢字配当表（2020年度から・1026字。`src/lib/kanji.ts`）で、その学年までに習っていない漢字がある言葉は、ふりがなの記法 `{漢字|よみ}` で届いても、言葉ごと読み（ひらがな）で出す（例：3年生には「{値段|ねだん}」→「ねだん」）。「本体」の「体」だけひらがな、のような まぜ書きはしない。配当表にない漢字（中学で習う漢字）は、6年生でも ひらがなにする（`src/lib/ruby.ts` の `sanitizeRuby`、`src/components/RubyText.tsx`）
- AI が書いた文（問い・解説・選択肢 など）は、ふりがなの記法 `{漢字|よみ}` で届く（`docs/03-technical.md` 5.2）。大きい文字ではふりがなにし、小さい文字では読みに置きかえて ひらがなで出す
- 答えの単位（回・個・日分 など）は、AI がふりがなを付けないので、アプリで付ける（大きい文字はふりがな、小さい文字はひらがな）
- 数の書き方：9999 まではそのまま（1000 からはカンマ区切り）。1万から上は「万・億・兆・京」を使い、上から4けたに丸める（例：123456789 →「1億2350万」）。桁が多くても画面からはみ出さないようにするため。大きい文字では、習った学年（万・京＝2年、億・兆＝4年）からは漢字にふりがなを付け、それより前の学年では ひらがなで書く（3年生なら「1おく2350万」）。小さい文字では学年によらず「1おく2350まん」とひらがなで書く（`src/lib/format.ts` の `numberRuby`・`formatNumber`）
- 文は、ことばの区切りに空白を入れる（わかち書き）。ひらがなだけの文は、区切りがないと読めないため

### 2.2 ことばの言いかえ
ひらがなにするときは、むずかしい熟語の読みを そのまま書かない（例：「前提」→「ぜんてい」「まえてい」としない）。小学生が知っている、やさしいことばに言いかえる。アプリの文言にも、AI が書く文（プロンプトで指示する）にも使う。

| むずかしいことば | 言いかえ（例） |
|---|---|
| 前提・仮定 | 「〜と する」「〜と かんがえる」（例：おふろは 200L と する）／「こたえの もとに なった データ」 |
| 根拠 | わけ |
| 条件 | きまり、〜のとき（「じょうけん」は「もしも」の画面だけで使う） |
| 単元 | 「にている はてな」など、何を指すかを言う |
| 確率 | 「〜回に 1回くらい」 |
| 推定・概算 | だいたい、やく |
| 比較 | くらべる |
| 保存・削除 | のこす、けす |
| 許可 | 「〜して いいよ」の せってい |
| 位置 | ばしょ（「いち」は数字の1と読めるので使わない） |
| 進級したら | 「がくねんが あがったら」 |
| 本名 | ほんとうの なまえ |
| 共有 | 「クラスに みせる」など、誰に見せるかを言う |

- 言いかえで決まった名前（はてな・こたえあわせ・なぞとき・もしも・はてなずかん・しょうごう）は、`docs/design/README.md` の「子どもが見る言葉」に合わせる
- 言いかえが思いつかないときは、表に足してからチームで確認する

### 2.3 そのほか
- 単位：その学年で習ったものに限る
- 文言：小学生が読める平易な日本語。専門用語には短い説明を添える
- 通信：オンライン必須。通信できないときはエラーを表示する
- エラー時：子どもにも分かるメッセージと、やり直すボタンを出す
  - 予期しないエラー（`src/app/error.tsx`・`global-error.tsx`）と、ない URL（`not-found.tsx`）も、ナビの「ぽかん」の表情と、「あれれ？ うまくいかなかったよ／みつからないよ」の文、「もういちど ためす」（エラーのときだけ）・「ホームに もどる」のボタンを出す（`src/components/ErrorScreen.tsx`）。ログには、エラーの種類と識別子だけを出す
  - 読み込みに失敗したときは、「データがない」と見せない。ずかん・スタンプは「よみこめなかったよ」とやり直すボタンを出す。プロフィールの読み込みに失敗したときは、はじめての登録の画面へ進ませず、やり直しを出す。ずかんの読み込みに失敗したままのときは、出題済みの組み合わせが空で送られないよう、問いを作らず、やり直しを出す（`ArchiveProvider` の `status: "error"`・`reload`、`AuthProvider` の `profileFailed`・`retryProfiles`）
- ナビゲーターキャラ（ナビ）：問いの出題と解説を行う。7つの表情を場面で使い分ける（`docs/design/README.md`「ナビの表情」）。LLM の応答待ち（最大60秒）は「まめちしき」でつなぐ
- 押せるものと押せないものを、見た目で分ける
  - 押せるもの（ボタン・押して進むカード・選ぶボタン）：太い線と、下にずれた影。押すと沈む
  - 選ぶボタン（学年・予想の選択肢など）：選ぶ前も影つき。選んだら色がつき、押しこまれた形（影なし・少し下がる）になる
  - 押せないもの（お知らせ・説明・結果のカード・チップ）：線も影もなし。うすい色の地だけ（`src/components/ui.tsx` の `PANEL`。白い地の上に白いカードは置かない）
  - 入力欄：太い線だけ（影なし）。ナビのふきだし：線なし、`navi-light` の地と しっぽ（ピタリのときだけ `red-light`）
- 動き：答えの数がふえる動き・はんこ・ナビがはねる動きなど。動きを減らす設定（prefers-reduced-motion）のときは動かさない

## 3 起動・注意表示
- MVP での優先度：Should（実装済み）
- さがしに いく まえ：ホーム（と今日のお題）の「はてなを さがす！」を押したら、カメラを起動する前に、全画面の「でかける まえの やくそく」を出す。「やくそく する！」を押してから カメラを起動する（とりなおし・「もっと さがす！」から撮影へ行くときは出さない）

## 4 認証
- 学校版（未実装）で変更：学校アカウント（ボタン、またはメールとパスワード）を足し、はじめての案内を7つの手順にする。いまの方式も残す（`docs/06-school-expansion.md` 3・4章）
- 機能：サインアップ・ログイン・ログアウト
- 認証は自作せず Firebase Authentication を使う（方式は `docs/03-technical.md` 2.1）。ログイン画面はアプリで作る
- 入力項目：ログイン ID・パスワード（6文字以上）。はじめてのときは、パスワードを もう一度入れてもらう（打ちまちがいで戻れなくなるのを防ぐ）
- 画面の呼び方：内部の「ユーザー名」は、画面では「ログイン ID」と呼ぶ。プロフィールの「ニックネーム（アプリで よばれる なまえ）」とは別のものだと、両方の画面に書く（2回なまえを聞いているように見えないようにする）
- 「はじめて」（ID を つくる）と「つづきから」（ID で ログイン）は、見出し（はじめまして！／おかえり！）・上の色・ナビの表情・ボタン（ID を つくる！／ログイン）を変えて、ちがいが一目で分かるようにする
- ログイン ID には英数字・ひらがな・カタカナが使える（内部で英数字に変換してから登録する）
- ログイン ID の長さの上限：【未決】。仮の実装：変換後 32 バイトまで（ひらがなで10文字、英数字で32文字）
- パスワードリセット：なし（メールアドレスを集めないため。パスワードを忘れるとアーカイブに戻れない。画面で「ID と パスワードを おうちの ひとと メモしてね」と伝える）

### 4.1 はじめての登録（`docs/06-school-expansion.md` 4.1 のうち、ログイン ID の方式）
- 見た目と文言は `docs/design/first/`（見本 01〜06・11・12。決まりは同じフォルダの `README.md`）。本名・学校のメールアドレス・クラスのコードの手順は入れない（学校での利用は構想のため）
- ナビが1画面に1つずつ聞く：ようこそ →「はじめる！」→ ① ログイン ID → ② パスワード → ③ ニックネーム → ④ 学年 → じゅんび できたよ
  - ①〜④ は、上に もどるボタンと進み具合（バーと「1/4」）を出す。入れおわるまで下のボタンは押せない（うすくする）
  - もどるボタンで前の手順へ戻っても、入れたものは消さない。③ では もどるボタンを出さない（② で ID を もう作ったため）
  - ① で、使えない文字・長すぎる ID は その場で知らせる（② へ進ませない）
  - ② は2回入れる。6文字以上か、2回目が同じかを その場で知らせる。「ID を つくる！」で アカウントを作る（ID が使われているかは、作るときにしか分からないため）
  - ② で ID が使われていたら ① に戻して「その ID は つかわれてるよ」と出す（見本 12）。入れた ID は残し、同じ ID のままでは押せない。パスワードは入れなおさない。「この ID で つくる！」で そのまま作って ③ へ
  - ④ の「けってい！」でプロフィールを作る。じゅんび できたよ では、ニックネーム・学年・ログイン ID を まとめて見せる
  - じゅんび できたよ の「あそびかたを みる！」→ ホーム（4.2 の説明が出る）／「とばして はじめる」→ ホーム（説明を見おわったことにする）

### 4.2 あそびかたの説明（`docs/06-school-expansion.md` 4.2）

## 5 プロフィール
- 学校版（未実装）で変更：学校アカウントの子どもは本名も扱う。ニックネームは「ユーザー名」として、クラス・グループに表示する（`docs/06-school-expansion.md` 3.2）
- 項目：ニックネーム（10文字まで）・学年のみ（本名は扱わない。画面で「ほんとうの なまえは いれないでね」と伝える）
- 初回のプロフィール作成時に学年を聞く（4.1 の ③・④）
- 学年はせっていの画面から変えられる（進級時など）。ニックネームはプロフィールの画面で変える
- 学年は問題の大まかな目安（4年生までと5年生からで、予想の入力方法を変える など）。問題の難しさの成長は 17章の「学習の進み具合」で決める
- 1アカウントに複数プロフィールを持てるデータ構造にする。切り替え画面は MVP 以降

## 6 撮影
- カメラで撮影する／アルバムから選ぶ（ホームからも選べる）
- カメラが使えないとき（許可がない・HTTPS でない）は、アルバムから選ぶよう案内する
- アルバムの写真が開けないとき（iPhone の HEIC など）は、カメラで撮るか別の写真を選ぶよう案内する
- 見本の絵（ガチャ・信号・氷のコップ）：ホームに置く。撮影できないときや AI が使えないときでも、囲む操作から最後まで試せる

## 7 囲む
- 自由な投げ縄で囲む（青い線と黄色いふち。囲んだ外側を少し暗くする）
- 「もどす」（囲み直し）・「とりなおす」（撮影へ）
- 囲めなかった・小さすぎるとき：「ちいさすぎるよ。もういちど おおきく かこんでね」
- 囲んだ直後から裏で LLM の呼び出しを始める（先読み生成。送るのは囲んだ範囲の切り抜きだけなので、囲む前には呼べない）

## 8 待ち・認識結果の確認
- 待ち（「みつけた！」）：切り抜きを丸く見せ、進み具合のバーの上をナビが歩く。まめちしきを10秒ごとに入れかえる。問いができたら「できた！ みてみる」を出し、押すと「これは○○だね？」へ進む
- 「これは○○だね？」と表示し、「うん！」なら問いの選択へ
- 「ちがうよ」なら、「しゃしんを とりなおす」「かこみなおす」を出す
- 問いが作れない写真なら、撮り直し・囲み直しを促す
- LLM に断られた（refusal）ときは「べつの ものを かこんでみてね」と表示する

## 9 問いの選択
- 自分で問いを書く方式と3択方式を切り替えられる。どちらも MVP の Must
- どちらを先に出すかは、せっていの画面で選ぶ
- 問いのタイプ：数量推定（いくつ？）・比較（くらべる）・「なぜ？」型（理由・結果・どっち、を並べた選択式。数字を使わなくてよい）。3つの問いのうち、「なぜ？」型を1つ以上、数で答える問い（数量推定・比較）は2つまでにする。問いは、囲んだ「そのもの自身」のふしぎを聞くものにし、細かい条件や専門の数をならべない・そのものと関係のない話にこじつけない（`docs/03-technical.md` 5.3）
- 3択のカードは、分類の色（さんすう＝青、りか＝みどり、じょうほう＝むらさき）と、分類・タイプの小さな見出しを出す
- 自分で書いた問いの扱い：LLM が式と変数を作り、答えはアプリ側で計算する（`docs/03-technical.md` 4章。LLM に計算はさせない）
- 自分で書く画面では「なんかい？」「どっちが おおきい？」「なぜ？」から書きはじめられる
- 自分で書いた問いが答えられない・不適切なとき：ナビが「べつの はてなに してみてね」と伝え、「3つの はてなから えらぶ」ボタンを出す
- 3択で気に入らないとき：「ほかの はてなを だす」で作り直す（ユーザーの操作で1回呼ぶ。自動リトライではない）
- 問いの質：「予想がはずれて、おどろく」問いにする（数えるだけの問い・1回のかけ算で出る問いは出さない）
- AI が使えず見本の問いに切りかえたときは、「みほんの はてなだよ（AIは つかっていないよ）」と出す

## 10 予想の入力（せーの！）
- 学年で切り替える
  - 数量を予想する問い：4年生まで＝5つの範囲から選ぶ（点の多さのアイコンつき）。5年生から＝スライダー（対数の目盛り）と、数の直接入力（大きな黄色の箱）
- 比較型の問い
  - 4年生まで：「どっちが おおきい？」の2択のあと、「やく ○ばい」を選択肢から選ぶ
  - 5年生から：何倍かをスライダーで入力する
- 「なぜ？」型：2〜3つの選択肢（理由・結果・どっち）から選ぶ
- 予想の範囲の真ん中（スライダーのはじめの位置・5つの範囲の真ん中）が、答えにならないようにする
- 入力欄を空にしたときは「せーの！」を押せない
- 「せーの！」を押すと、そのまま答え合わせを見せる（予想を入力するまで答えを見せない）

## 11 答え合わせ・可視化（こたえあわせ）
- 予想を入力するまで答えを見せない
- 評価ごとに、ナビの表情・ふきだし・はんこを変える
  - ピタリ（誤差±5%以内）：赤びっくり・「ピタリ！ すごい！」・赤いはんこ（赤は正解だけに使う）
  - おしい（予想の 1/2〜2倍）：照れ・「おしい！ あと すこし！」・オレンジのはんこ
  - 大はずれ（それ以上）：青びっくり・「こんなに ちがうの！？」・青いはんこ
- 答えの数を大きく出し（数がふえる動き）、「よそうの やく○ばい！」「ほぼ ぴったり！」を添える
- 数直線：ふつうの目盛り（0から、予想と答えに合わせて右はしを決める）。ピンクの丸＝きみ、青い旗＝こたえ、黄色い帯＝ずれ。旗が予想の位置から答えの位置へ動く（ズレが見た目の長さにそのまま出る）
- 身近なものへの置き換え（「1ねん（365にち）だと 350,400かい」など）を出す
- 「なぜ？」型は、正解・不正解（せいかい！／ざんねん…）と、正解の理由を出す
- 比較型は、大きいほうを当てたかと、どちらが大きいかも出す

## 12 解説（なぞとき）
- ナビがまず一言で説明し、計算の手順（番号つき・色つきのカード）を はじめから見せる（見本 17。ずかんの詳細では「くわしく みる」で開く）
- 直感が当たった場合も同じ解説を見せる
- 「ほかにも こんな ふしぎが あるよ」（関連する問い）と、「こたえの もとに なった データ」（出典・考えたときの決まり・しらべることば）を出す。リンクは「おとなの ひとと いっしょに みてね」と添える
- 条件を変えられる問いだけ「もっと！」ボタンを出す（見本 17。押すと「もっとしりたい！」の画面＝13章）

## 13 条件変更（もしも）
- 変数をスライダーで動かし、アプリ側で再計算する
- 変化が一目で分かるようにする
  - スライダーに、もとの値の目印を残す（「もとは ○」「もとに もどす」）
  - 答えを大きく出し、「▲ もとの やく○ばい」「▼ もとの やく○ぶんの1」を添える
  - 「さっき」と「いま」の ぼうグラフをならべる
- 条件のといかけ（「じゃあ、40しゅるいだったら？」）をナビのふきだしに出す

## 14 アーカイブ（はてなずかん）
- 保存するもの：写真（切り抜きのみ）・問い・予想・結果
- 保存の前に「なかまにも みせる」で、入っているグループから見せるものを選べる（いくつでも。はじめは どれも選ばない。15章）。グループに入っていないときは出さない。保存すると「はてなゲット！」とスタンプを見せる。ずかんには のこせて、グループに見せられなかったときは「ずかんには のこせたけど、なかまには みせられなかったよ」と出す
- 一覧：上の段は3分類のタブ（さんすう／りか／じょうほう。数つき）、下の段は単元のタブ（すべて・…。横にスクロール）。えらんだ分類で画面の地の色を うすく変える。保存した問い（切り抜き・問い・単元・日付・評価の札）。1つもないときは「まだ ないよ」
- 分類：算数・理科・情報の3分類の下を、さらに単元（面積・速さ・割合など）で分ける。仮の実装：単元のタブは AI が返す `topic` をそのまま使い、一覧は新しい順にならべる。詳細で「にている はてな」（同じ単元）を出す
- スタンプカードと称号は、スタンプの画面（`/stamp`）に出す（16章）
- 詳細でできること：答え合わせの見返し、解説、条件変更、出典の確認、関連する問い、なかまに みせるのを やめる（見せているグループの名前も出す）、けす（同じ問いへの再挑戦はなし）
- 削除：「えらんで けす」で個別・まとめて（「ぜんぶ えらぶ」）消せる。消す前に確認する
- 本人（プロフィール）しか読み書きできない（グループに見せたものを除く。15章）。学校版（未実装）で変更：授業時間中に保存したものは、担当クラスの先生も読める（`docs/06-school-expansion.md` 5.2）
- 保持期間：本人が削除するまで保持する。学校版（構想）で変更：学校のデータは、学校での利用が終わったら決めた期限内に消す（`docs/06-school-expansion.md` 9章）

## 15 ミッション・他の人の問題
- ミッション（今日のお題。MVP の Should・実装済み）：ホームとお題の画面に出す。日付ごとに1つ（通知はしない）。その日にずかんに保存したら「クリア！」
  - 学校版（未実装）で変更：先生がクラスごとに文章と日付を決められる（`docs/06-school-expansion.md` 5.3）
- 他の人の問題（みんなの はてな。MVP の対象）：入っているグループの なかまが見せた問いを見る（グループごとに新しい順に30件）。2026-11-06 に決めた（#120）
  - 全員への匿名公開はやめ、グループの中だけで見せあう形に置きかえた
  - グループ：**JPHACKS**（発表の日に、JPHACKS の参加者がおたがいの はてなを見る。新しく登録した人は自動で入る）と **C専会**（チームメンバーの確認用。手で入れる）と **C3**（手で入れる。2026-11-06 に足した）。チームメンバーは JPHACKS と C専会の両方に入る
  - 見出しは「みんなの はてな」のまま、その下に「JPHACKS」「C専会」「C3」のうち入っているものの切り替えを出す（入っているのが1つなら、その名前だけ。3つならぶときは 22px に収まらないので、小さい文字で ひらがな・英数字で書く）。下のナビは「みんな」のまま。どこにも入っていないときは「まだ どの グループにも はいっていないよ」と出す
  - 見せるのは切り抜き画像・問い・称号だけ。ユーザー名・ニックネーム・位置情報は含めない。画面で「なまえは でないよ」と伝える。「きみの はてな」の印は、自分のずかんで そのグループに見せているものに出す
  - JPHACKS は登録した人がだれでも入るので、実質だれでも見られる。名前を出さないことと、管理者がすぐ消せることを必ず守る
  - 通報：「みんなの はてな」のほかの人の はてなに、小さな「つうほう」がある。押すと「いやな はてな？ おとなに おしらせするよ」と たずね、「おしらせ」で通報できる（通報した人は「つうほう したよ。ありがとう」と出る。同じ人の同じ はてなの2回目は、1件にしかならない）。自分の はてなには出さない。通報された投稿は、すぐには隠さず、管理画面で先頭に出して「通報 ○件」と見せる（通報した人は、管理者にも分からない）。通報は、グループのメンバーなら だれでもできる（#85。2026-11-06）

## 16 収集要素（MVP の Must）
- 算数／理科／情報の3分類ごとにスタンプカードを用意する。ずかんに1つ保存するごとに、その分類のスタンプが1つふえる
- 決まった数を集めると称号を得られる
- 称号は切り替えられ、グループに問題を見せるときに表示される。スタンプの画面で「スタンプカード」と「しょうごう」を切りかえ、もらった称号から1つえらぶ（まだのものは、かぎと「あと ○こ」）
- はじめから持っている称号：仮の実装「はてなハンター」（称号をえらんでいないとき。`docs/design/README.md` では仮）
- 称号を得るのに必要な個数：【未決】。仮の実装：5個（`docs/design` の見本と同じ）
- 称号の名前：仮の実装「すうがく はかせ」「りか マスター」「エンジニア レベル」（`docs/design/README.md` では仮）

## 17 問題の成長（MVP の Must）
- アプリでの学習の進み具合に応じて、出す問いを高度にしていく（同じシチュエーションを撮ったときに、以前より高度な問いが出るようにする）
- 学年は大まかな目安として使う（5章）
- 学習の進み具合の測り方と、問いへの反映のしかた：【未決】。仮の実装：ずかんの件数から「レベル1〜5」（4件ごとに1つ上がる）を決め、学年・出題済みの組み合わせといっしょにプロンプトへ渡す（`src/lib/progress.ts`）
