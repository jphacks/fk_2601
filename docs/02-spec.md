## 2 共通の決まり
### 2.1 文字
- 学校版の管理画面（未実装）は大人向けなので、2.1・2.2 の決まりを使わない。ただし、先生が書いたミッションを子どもの画面に出すときは使う（`docs/06-school-expansion.md` 5章・5.3）
- 22px 以上の文字の漢字には、すべてふりがなを振る。それより小さい文字は、ふりがなを振らず、その学年までに習った漢字は漢字のまま、習っていない漢字は ひらがなで書く（小さい文字のふりがなは、つぶれて読めないため。2026-11-13 に決めた。#175。`docs/design/README.md`「文字」）
- この決まりは、AI が書いた文だけでなく、ホーム・ずかん・せってい など 子どもの画面の すべての文言に使う。画面の文言は ふりがなの記法 `{漢字|よみ}` で書き、`<Jp>` で出す（`src/components/RubyText.tsx`）。学年が まだ ないとき（はじめての登録の とちゅう）は、すべて ひらがなで出す
- 漢字は学年の漢字配当に合わせる。学年別漢字配当表（2020年度から・1026字。`src/lib/kanji.ts`）で、その学年までに習っていない漢字がある言葉は、ふりがなの記法 `{漢字|よみ}` で届いても、言葉ごと読み（ひらがな）で出す（例：3年生には「{値段|ねだん}」→「ねだん」）。「本体」の「体」だけひらがな、のような まぜ書きはしない。配当表にない漢字（中学で習う漢字）は、6年生でも ひらがなにする（`src/lib/ruby.ts` の `sanitizeRuby`、`src/components/RubyText.tsx`）
- AI が書いた文（問い・解説・選択肢 など）は、ふりがなの記法 `{漢字|よみ}` で届く（`docs/03-technical.md` 5.2）。大きい文字ではふりがなにし、小さい文字では ふりがなを付けずに出す（習っていない漢字は読み）
- 答えの単位（回・個・日分 など）は、AI がふりがなを付けないので、アプリで付ける（大きい文字はふりがな、小さい文字は学年に合わせて漢字か ひらがな）
- 数の書き方：9999 まではそのまま（1000 からはカンマ区切り）。1万から上は「万・億・兆・京」を使い、上から4けたに丸める（例：123456789 →「1億2350万」）。桁が多くても画面からはみ出さないようにするため。大きい文字では、習った学年（万・京＝2年、億・兆＝4年）からは漢字にふりがなを付け、それより前の学年では ひらがなで書く（3年生なら「1おく2350万」）。小さい文字では学年によらず「1おく2350まん」とひらがなで書く（`src/lib/format.ts` の `numberRuby`・`formatNumber`）
- 文は、ことばの区切りに空白を入れる（わかち書き）。ひらがなだけの文は、区切りがないと読めないため

### 2.2 ことばの言いかえ
ひらがなにするときは、むずかしい熟語の読みを そのまま書かない（例：「前提」→「ぜんてい」「まえてい」としない）。小学生が知っている、やさしいことばに言いかえる。アプリの文言にも、AI が書く文（プロンプトで指示する）にも使う。

| むずかしいことば | 言いかえ（例） |
|---|---|
| 前提・仮定 | 「〜と する」「〜と かんがえる」（例：おふろは 200L と する）／「こたえの もとに なった データ」 |
| 根拠 | わけ |
| 条件 | きまり、〜のとき（「じょうけん」は「もしも」の画面だけで使う） |
| 単元 | 「にている はてな」など、何を指すかを言う |
| 確率 | 「〜回に 1回くらい」 |
| 推定・概算 | だいたい、やく |
| 比較 | くらべる |
| 保存・削除 | のこす、けす |
| 許可 | 「〜して いいよ」の せってい |
| 位置 | ばしょ（「いち」は数字の1と読めるので使わない） |
| 進級したら | 「がくねんが あがったら」 |
| 本名 | ほんとうの なまえ |
| 共有 | 「クラスに みせる」など、誰に見せるかを言う |

- 言いかえで決まった名前（はてな・こたえあわせ・なぞとき・もしも・はてなずかん・しょうごう）は、`docs/design/README.md` の「子どもが見る言葉」に合わせる
- 言いかえが思いつかないときは、表に足してからチームで確認する

### 2.4 学年ごとの表記（2026-11-06 に決めた。#100）
学年ごとの決まりは、コードでは1か所にまとめる（漢字：`src/lib/kanji.ts`・`src/lib/ruby.ts`、数：`src/lib/format.ts`、AI への指示：`src/server/llm/prompts.ts`）。学年は、学習指導要領で習う学年に合わせる

| 表記 | 何年生から | それより前の学年 |
|---|---|---|
| 漢字 | 学年別漢字配当表のとおり | 言葉ごと ひらがなで書く（2.1） |
| 万・京 ／ 億・兆 | 2年 ／ 4年 | ひらがなで書く（「1おく2350万」） |
| 小数 | 3年 | 1より大きい数は、整数にまるめて出す（5つの範囲の選択肢・数直線・答えの数・ずかん）。倍の選択肢は 2・3・4・5・10・20・50・100倍（1.5倍を出さない）。1より小さい数は、そのまま出す |
| 分数（○分の1） | 3年 | 「よそうより ずっと／すこし すくない」と言う（2倍より大きく ちがうとき「ずっと」） |
| 倍 | 2年 | 「よそうより ずっと／すこし おおい」と言う。AI には、1年生に compare（何倍）の問いを作らせない（ほかの問いがあるときは、サーバーでも はずす） |
| 割合・％ | 5年 | AI に「10回に1回」のように言わせる |
| 単位 | その学年で習ったもの（2.3。学年ごとの一覧は `src/server/llm/prompts.ts` の `UNITS`） | AI に、習った単位だけを使わせる |

- 予想の入れかた（4年生までは5つの範囲、5年生からはスライダー）は 10章のとおり

### 2.3 そのほか
- 単位：その学年で習ったものに限る
- 文言：小学生が読める平易な日本語。専門用語には短い説明を添える
- 通信：オンライン必須。通信できないときはエラーを表示する
- エラー時：子どもにも分かるメッセージと、やり直すボタンを出す
  - 予期しないエラー（`src/app/error.tsx`・`global-error.tsx`）と、ない URL（`not-found.tsx`）も、ナビの「ぽかん」の表情と、「あれれ？ うまくいかなかったよ／みつからないよ」の文、「もういちど ためす」（エラーのときだけ）・「ホームに もどる」のボタンを出す（`src/components/ErrorScreen.tsx`）。ログには、エラーの種類と識別子だけを出す
  - 読み込みに失敗したときは、「データがない」と見せない。ずかん・スタンプは「よみこめなかったよ」とやり直すボタンを出す。プロフィールの読み込みに失敗したときは、はじめての登録の画面へ進ませず、やり直しを出す。ずかんの読み込みに失敗したままのときは、出題済みの組み合わせが空で送られないよう、問いを作らず、やり直しを出す（`ArchiveProvider` の `status: "error"`・`reload`、`AuthProvider` の `profileFailed`・`retryProfiles`）
- ナビゲーターキャラ（ナビ）：問いの出題と解説を行う。7つの表情を場面で使い分ける（`docs/design/README.md`「ナビの表情」）。LLM の応答待ち（最大60秒）は「まめちしき」でつなぐ
- 押せるものと押せないものを、見た目で分ける
  - 押せるもの（ボタン・押して進むカード・選ぶボタン）：太い線と、下にずれた影。押すと沈む
  - 選ぶボタン（学年・予想の選択肢など）：選ぶ前も影つき。選んだら色がつき、押しこまれた形（影なし・少し下がる）になる
  - 押せないもの（お知らせ・説明・結果のカード・チップ）：線も影もなし。うすい色の地だけ（`src/components/ui.tsx` の `PANEL`。白い地の上に白いカードは置かない）
  - 入力欄：太い線だけ（影なし）。ナビのふきだし：線なし、`navi-light` の地と しっぽ（ピタリのときだけ `red-light`）
- 動き：答えの数がふえる動き・はんこ・ナビがはねる動き・答え合わせと保存の お祝いの演出（11・14章）など。動きを減らす設定（prefers-reduced-motion）のときは動かさない（じらす間も とばして、結果を すぐ出す）
- 飾りや演出で、画面が 横に スクロールしないようにする（画面の枠 `Page` で、横の はみ出しを 切る）

## 4 認証
- 学校版（未実装）で変更：学校アカウント（ボタン、またはメールとパスワード）を足し、はじめての案内を7つの手順にする。いまの方式も残す（`docs/06-school-expansion.md` 3・4章）
- 機能：サインアップ・ログイン・ログアウト・アカウントの削除
- 認証は自作せず Firebase Authentication を使う（方式は `docs/03-technical.md` 2.1）。ログイン画面はアプリで作る
- 入力項目：ログイン ID・パスワード（6文字以上）。はじめてのときは、パスワードを もう一度入れてもらう（打ちまちがいで戻れなくなるのを防ぐ）
- 画面の呼び方：内部の「ユーザー名」は、画面では「ログイン ID」と呼ぶ。プロフィールの「ニックネーム（アプリで よばれる なまえ）」とは別のものだと、両方の画面に書く（2回なまえを聞いているように見えないようにする）
- 「はじめて」（ID を つくる）と「つづきから」（ID で ログイン）は、見出し（はじめまして！／おかえり！）・上の色・ナビの表情・ボタン（ID を つくる！／ログイン）を変えて、ちがいが一目で分かるようにする
- ログイン ID には英数字・ひらがな・カタカナが使える（内部で英数字に変換してから登録する）
- ログイン ID の長さの上限：【未決】。仮の実装：変換後 32 バイトまで（ひらがなで10文字、英数字で32文字）
- パスワードリセット：なし（メールアドレスを集めないため。パスワードを忘れるとアーカイブに戻れない。画面で「ID と パスワードを おうちの ひとと メモしてね」と伝える）

### 4.1 はじめての登録（`docs/06-school-expansion.md` 4.1 のうち、ログイン ID の方式）
- 見た目と文言は `docs/design/first/`（見本 01〜06・11・12。決まりは同じフォルダの `README.md`）。本名・学校のメールアドレス・クラスのコードの手順は入れない（学校での利用は構想のため）
- ナビが1画面に1つずつ聞く：ようこそ →「はじめる！」→ ① ログイン ID → ② パスワード → ③ ニックネーム → ④ 学年 → じゅんび できたよ
  - ①〜④ は、上に もどるボタンと進み具合（バーと「1/4」）を出す。入れおわるまで下のボタンは押せない（うすくする）
  - もどるボタンで前の手順へ戻っても、入れたものは消さない。③ では もどるボタンを出さない（② で ID を もう作ったため）
  - ① で、使えない文字・長すぎる ID は その場で知らせる（② へ進ませない）
  - ② は2回入れる。6文字以上か、2回目が同じかを その場で知らせる。「ID を つくる！」で アカウントを作る（ID が使われているかは、作るときにしか分からないため）
  - ② で ID が使われていたら ① に戻して「その ID は つかわれてるよ」と出す（見本 12）。入れた ID は残し、同じ ID のままでは押せない。パスワードは入れなおさない。「この ID で つくる！」で そのまま作って ③ へ
  - ④ の「けってい！」でプロフィールを作る。じゅんび できたよ では、ニックネーム・学年・ログイン ID を まとめて見せる
  - じゅんび できたよ の「あそびかたを みる！」→ ホーム（4.2 の説明が出る）／「とばして はじめる」→ ホーム（説明を見おわったことにする）
- 2回目から：ようこそ →「つづきから（ID を もっている ひと）」→ おかえり（ID と パスワードの1画面）→ ホーム。あそびかたの説明は出さない
- 登録の途中で アプリを閉じたとき：② のあと（アカウントだけある）は、次に開くと ③ から。④ のあと（じゅんび できたよ の前）は、次に開くと ホームで 4.2 の説明が出る

### 4.2 あそびかたの説明（`docs/06-school-expansion.md` 4.2）
- 見本は `docs/design/first/` 07〜09・10。ホームを暗くして（`ink` の 74%）、その上に3枚の説明を出す。いま説明しているものだけ暗くしない（押せないようにする）
  1. あそぶ じゅんばん：さがす → かこむ → えらぶ → せーの！ → こたえあわせ → もしも → のこす
  2. 下のナビ：5つ（ずかん・スタンプ・ホーム・みんな・せってい）が何をするところか
  3. はてなを さがす！：撮影のボタンを黄色の点線で囲む。「やってみる！」→ やくそく → カメラ／「ホームを みる」→ 閉じる
- どの1枚でも「とばす」（3枚目は「とじる」）で閉じられる
- はじめての1回だけ出す。判定はアカウントごと（保存先は `docs/03-technical.md` 6章の `guideSeenAt`）
- せっていの「あそびかたを もういちど みる」（`/?guide=1`）で、1枚目から もういちど見られる。閉じると URL は `/` に戻る
- `/demo` では出さない（見本のプロフィールは見おわったとして扱う）

### 4.3 アカウントをけす（退会）
- せっていの「アカウントを けす」から確認画面を出す。ずかん・なかまに見せたはてな・全プロフィール・ログイン ID が消え、元に戻せないことを伝える。「せっていに もどる」でやめられ、「ぜんぶ けす」で実行する
- Firebase 版は、消す前にパスワードをもう一度入力し、Firebase Authentication の再認証をする。まちがっていたら何も消さず、入れなおせる。パスワードは保存しない
- 削除順：全グループの自分の投稿と持ち主の記録 → 全グループの自分のリアクション（15章） → 全プロフィールのずかん（記録と、別に分けた大きな切り抜き `archiveImages`） → グループの参加情報 → 全プロフィールとユーザーの文書 → Authentication のアカウント。公開中の投稿を消せなかったら、それより後は消さない
- 削除中は二重に押せないようにし、ほかの画面へのボタンを出さない。完了したらログイン画面へ戻る
- 途中で失敗したら「ぜんぶは けせなかったよ。ネットに つながっているか みて、もういちど ためしてね」と「もういちど ためす」を出す。消せたデータは戻らない。やり直しは残りを消す
- 削除の途中で再ログインを求められたら「もういちど パスワードを いれて、ためしてね」と出し、同じ確認画面で再認証してやり直す。プロフィール削除後も `/settings` でやり直せる
- ローカル版も同じ確認と削除順にする。パスワードは保存も確認もしないため、再入力は求めない。他のアカウントのデータは消さない

## 6 撮影
- カメラで撮影する／アルバムから選ぶ（ホームからも選べる）
- カメラが使えないとき（許可がない・HTTPS でない）は、アルバムから選ぶよう案内する。案内の文の下に「アルバムから えらぶ」のボタンを 大きく出す（つぎに できることが、ひと目で分かるように。ねらいの かどと ナビの ひとことは 出さない。#191）
- アルバムの写真が開けないとき（iPhone の HEIC など）は、カメラで撮るか別の写真を選ぶよう案内する
- 見本の絵（ガチャ・信号・氷のコップ）：ホームの「みほんの えで ためす」から、一覧の画面（`/samples`）を開いて えらぶ（#191。前は ホームに 3まい ならべていた：#169）。撮影できないときや AI が使えないときでも、囲む操作から最後まで試せる。一覧は、絵と名前（「ガチャガチャ」「しんごう」「こおり」）の 大きなカードを たてに ならべる。えらぶと 囲む画面へ進む
- ホームは、スクロールしなくても ぜんぶ 見える（390×844 と 375×667）。まちの絵は、画面の たかさに合わせて ちぢむ（230px まで）。のこった たかさは 空が うめる

## 7 囲む
- 自由な投げ縄で囲む（青い線と黄色いふち。囲んだ外側を少し暗くする）
- 「もどす」（囲み直し）・「とりなおす」（撮影へ）
- 写真は、下のボタン（もどす・とりなおす・OK！）まで スクロールしなくても見える たかさに おさめる（たて横の比は そのまま。#191。前は たてに長い写真だと、「OK！」が 下の2つのボタンに 重なっていた）。ナビは 小さな ふきだしで ひとことだけ言う（囲む前「きになる ところを ゆびで ぐるっと かこもう！」／囲んだあと「これで いいかな？ 「OK！」を おしてね」）
- 囲めなかった・小さすぎるとき：「ちいさすぎるよ。もういちど おおきく かこんでね」
- 囲んだ直後から裏で LLM の呼び出しを始める（先読み生成。送るのは囲んだ範囲の切り抜きだけなので、囲む前には呼べない）

## 8 待ち・認識結果の確認
- 待ち（「みつけた！」）：切り抜きを丸く見せ、進み具合のバーの上をナビが歩く。まめちしきを10秒ごとに入れかえる。問いができたら「できた！ みてみる」を出し、押すと「これは○○だね？」へ進む。押さなくても、1.5秒たつと自動で進む（手数を1つ へらすため。#126）
  - 進み具合のバーの下の「もうすこし！ 1ぷんくらい かかる ことも あるよ」は、15秒たっても できないときだけ出す（ふだんは 約20秒で できるので、はじめから出して「1分も待つのか」と思わせない）。デモ版（`/demo`）では出さない（#169。`src/components/Loading.tsx`）
  - 待っているあいだは、「まめちしき」と、ミニゲーム「はてなキャッチ」を切りかえられる（はじめは まめちしき）。はてなキャッチは、出てくる「？」を さわって つかまえる遊び。失敗はなく、つかまえた数だけを数える。はてなが できたら、新しい「？」は出さない（#127。`src/components/Loading.tsx`）
- 「これは○○だね？」と表示し、「うん！」なら問いの選択へ
- 「ちがうよ」なら、「しゃしんを とりなおす」「かこみなおす」を出す
- 問いが作れない写真なら、撮り直し・囲み直しを促す
- LLM に断られた（refusal）ときは「べつの ものを かこんでみてね」と表示する

## 9 問いの選択
- 自分で問いを書く方式と3択方式を切り替えられる。どちらも MVP の Must
- どちらを先に出すかは、せっていの画面で選ぶ
- 問いのタイプ：数量推定（いくつ？）・比較（くらべる）・「なぜ？」型（理由・結果・どっち、を並べた選択式。数字を使わなくてよい）。3つの問いのうち、「なぜ？」型を1つ以上、数で答える問い（数量推定・比較）は2つまでにする。問いは、囲んだ「そのもの自身」のふしぎを聞くものにし、細かい条件や専門の数をならべない・そのものと関係のない話にこじつけない（`docs/03-technical.md` 5.3）
- 3択のカードの問題文は3行までにし（長いときは「…」で省く。全文は 予想の画面で読める）、ナビのふきだし（「どの はてなが きになる？」）は 1行の小さな文字（ナビ 56px）にして、3つのカードと「ほかの はてなを だす」が スクロールしなくても 390×844 に入るようにする（#169）
- 3択のカードは、分類の色（さんすう＝青、りか＝みどり、じょうほう＝むらさき）と、分類・タイプの小さな見出しを出す
- 自分で書いた問いの扱い：LLM が式と変数を作り、答えはアプリ側で計算する（`docs/03-technical.md` 4章。LLM に計算はさせない）
- 自分で書く画面では「なんかい？」「どっちが おおきい？」「なぜ？」から書きはじめられる
- 自分で書いた問いが答えられない・不適切なとき：ナビが「べつの はてなに してみてね」と伝え、「3つの はてなから えらぶ」ボタンを出す
- 3択で気に入らないとき：「ほかの はてなを だす」で作り直す（ユーザーの操作で1回呼ぶ。自動リトライではない）
- 問いの質：「予想がはずれて、おどろく」問いにする（数えるだけの問い・1回のかけ算で出る問いは出さない）
- AI が使えず見本の問いに切りかえたときは、「みほんの はてなだよ（AIは つかっていないよ）」と出す

## 10 予想の入力（せーの！）
- 学年で切り替える
  - 数量を予想する問い：4年生まで＝5つの範囲から選ぶ（点の多さのアイコンつき）。5年生から＝スライダー（対数の目盛り。めもりは、はしの 数（min・max）を かならず出し、そのあいだに 10・100… を出す。はしに近すぎる 10 のべき乗は出さない。2〜100 なら「2・10・100」。#169）と、数の直接入力（大きな黄色の箱）
- 比較型の問い
  - 4年生まで：「どっちが おおきい？」の2択のあと、「やく ○ばい」を選択肢から選ぶ
  - 5年生から：何倍かをスライダーで入力する
- 「なぜ？」型：2〜3つの選択肢（理由・結果・どっち）から選ぶ。正解の位置は問いごとにランダム（サーバーで1回だけ並べかえる。#158）
- 予想の範囲の真ん中（スライダーのはじめの位置・5つの範囲の真ん中）が、答えにならないようにする
- 入力欄を空にしたときは「せーの！」を押せない
- 「せーの！」を押すと、そのまま答え合わせを見せる（予想を入力するまで答えを見せない）

## 11 答え合わせ・可視化（こたえあわせ）
- 予想を入力するまで答えを見せない
- じらしてから言う（#191。2026-11-14 に決めた）：はじめは ナビが 目を ぎゅっと つぶって「こたえは… どきどき…」と言い、答えの数が ふえていく（こきざみに ゆれる）。ふえおわってから（約1.2秒）、はんこを押して、ナビの表情・ふきだし・カードの色・ひとことの札を いっしょに出す。それまで 評価は 見せない（札の場所は 先に取っておき、出たときに 画面を ずらさない）。「なぜ？」型は 約0.9秒（「こたえは… どれかな…？」）。ずかんで見返すとき・動きを減らす設定のときは、じらさずに すぐ出す
- 評価ごとに、ナビの表情・ふきだし・はんこを変える
  - ピタリ（誤差±5%以内）：赤びっくり・「ピタリ！ すごい！」・赤いはんこ（赤は正解だけに使う）
  - おしい（予想の 1/2〜2倍）：照れ・「おしい！ あと すこし！」・オレンジのはんこ
  - 大はずれ（それ以上）：青びっくり・「こんなに ちがうの！？」・青いはんこ
- 評価ごとの演出（1回だけ出て、消える。押すのの邪魔をしない。`src/components/Decor.tsx`）
  - ピタリ・「なぜ？」型の正解：紙ふぶきが はじけて、上からも ふる（いちばん はなやかに。赤い紙も まぜる）
  - おしい：はんこの まわりで オレンジと黄色の紙が 小さく はじけ、星が きらっと 光る（ひかえめに）
  - 大はずれ：びっくりの線が まんなかから 外へ 広がり、「！？」が とび出して、答えのカードが ぶるっと ゆれる（はずれて おどろくのが、このアプリの中心なので、がっかり させずに おどろきを 大きく見せる）
  - どの評価でも、はんこを押した しゅんかんに 輪が 広がる
- 答えの数を大きく出し（数がふえる動き）、「よそうの やく○ばい！」「ほぼ ぴったり！」を添える
  - 範囲で予想したとき（4年生まで。#167。2026-11-13 に決めた）は、倍率ではなく、選んだ範囲との ちかさで言う：答えが選んだ範囲の中なら「ぴったり この はんい！」、となりの範囲なら「おしい！ となりの はんい」、それ以外は「よそうより ずっと おおい！／すくない！」。判定（ピタリ・おしい・大はずれ）は変えない。「きみの よそう：…」の行は出さない（数直線の帯の下に出すので）。ずかんの1件でも同じ
- 数直線：ふつうの目盛り（0から、予想と答えに合わせて右はしを決める）。ピンクの丸＝きみ、青い旗＝こたえ、黄色い帯＝ずれ。旗が予想の位置から答えの位置へ動く（ズレが見た目の長さにそのまま出る）。下の「こたえ ○」の文字は、旗が 答えに つくころに出す（上の数が ふえている とちゅうで、先に 見えないように）
  - 範囲で予想したとき：ピンクの丸のかわりに、選んだ範囲をピンクの帯で出し、帯の下に「きみ 2〜4.4」と書く。範囲の まんなかの数は、子どもが選んだ数ではないので、どこにも出さない。旗は帯の まんなかから答えへ動き、黄色い帯は、答えが範囲の外に出た分だけ出す
- 身近なものへの置き換え（「1ねん（365にち）だと 350,400かい」など）を出す
- 「なぜ？」型は、正解・不正解（せいかい！／ざんねん…）と、正解の理由を出す。じらす間は、えらんだ ものに「きみの よそう」とだけ出し、そのあと 正解の えらびに 色をつける。当てたときは、正解の えらびに はなまる（赤。ペンで かくように出る）を かさねる
- 余白：ナビの反応・答えのカード（と数直線）・身近なものへの置き換え・「なぞときへ！」のあいだに、のこった空白を 同じだけ分ける（`docs/design/README.md`「余白」。前は ぜんぶ ボタンの上に たまっていた）
- 比較型は、大きいほうを当てたかと、どちらが大きいかも出す

## 12 解説（なぞとき）
- 解説・やってみよう・出典などは、問いを作る1回目とは別に、子どもが問いを選んだときに、その1問だけ AI が作る（2回目。#165。`docs/03-technical.md` 5.4）。子どもが予想している あいだに終わるので、ふつうは待たない。「こたえあわせ」は2回目を待たない（答えと「身近なもので言うと」は1回目で届く）
  - 「なぞとき」に進んだとき、まだできていなければ、ナビと3つの点で「なぞを しらべているよ」を出して待つ（できたら自動で切りかわる）
  - できなかったときは、ナビの文（「うまくいかなかったよ。もういちど ためしてね」など）と「もう一度 ためす」（2回目だけをやりなおす）、「ほかの はてなを えらぶ」を出す。固まらない
  - 解説が届くまで、「ずかんに のこす」には進めない（解説が空の記録を ずかんに のこさないため）
  - 見本の問い・デモ・自分で書いた問いは、はじめから全部そろっているので、待たない
- ナビがまず一言で説明し、計算の手順（番号つき・色つきのカード）を はじめから見せる（見本 17。ずかんの詳細では「くわしく みる」で開く）
- 直感が当たった場合も同じ解説を見せる
- 「ほかにも こんな ふしぎが あるよ」（関連する問い）と、「こたえの もとに なった データ」（出典・考えたときの決まり・しらべることば）を出す。リンクは「おとなの ひとと いっしょに みてね」と添える
- 「おとなの 人へ」（#161。2026-11-14 に決めた）：「こたえの もとに なった データ」の中に、AI が書いた `basis`（正解の わけを、大人が教科書・図鑑で たしかめられる1文）を、小さい字で出す。保存された問いに `basis` が なければ出さない。ずかんの1件でも同じ。2回目で届く出典（`sources`）と いっしょに見える
  - AI は 問いを作るとき、正解の事実の たしかさ（`certainty`：`textbook`＝教科書・図鑑にのっている／`common`＝ひろく知られている／`guess`＝写真からの すいそく）も申告する。`guess` の問いと、「なぜ？」型の正解の選択肢（や解説の一言）に「かもしれない」「と おもう」「らしい」「たぶん」が入っている問いは出さない（`src/server/llm/validate.ts`）。3つとも出せなければ、いつもの エラー画面（やり直す）。AI の自己申告なので、完全ではない
- 「かんがえてみよう」（じゃあ、こうだったら？ の問いかけ。#168。2026-11-13 に決めた）：「なぜ？」型は、変えられる条件（スライダー）がなく「もしも」の画面が出ないので、AI が書いた `whatIf`（形・材料・ばしょが ちがったら どうなるか。答えは書かせない）を、「やってみよう！」の前に、ナビの「はてな」の顔つきの うすいむらさきのカードで出す。押せないので地の色だけ。`whatIf` が空のとき（前に保存した問いなど）は出さない。ずかんの1件でも同じ。答えが数の問いは「もっと！」の「もしも」（13章）のままで、このカードは出さない
- 「やってみよう！」（#124。2026-11-12 に決めた）：「ほかにも こんな ふしぎが あるよ」の前に、本物の ものに ふれて たしかめる観察を1つ出す（例：「からの ペットボトルと、水の 入った ペットボトルを、かたてずつ もって くらべてみよう」）
  - その場で、ひとりで、家や学校に ふつうに あるもので できる、ごく安全なものだけ。することは「みる・さわる・くらべる・かぞえる・さがす」だけ。外に出かけることは すすめない
  - 火・熱いもの・お湯・刃物・はさみ・電気・電池・薬・洗剤・高い所・道路・線路・川や池・口に入れる・知らない人、を使うものは出さない（AI に指示し、コードでも あぶない ことばを見つけたら「やってみよう」だけを消す：`src/server/llm/validate.ts`。問いは そのまま出す）
  - AI が書かなかったとき・前に保存した問いには、出さない
  - 結果をずかんに書きこむ機能は、まだ作らない【未決】
- 条件を変えられる問いだけ「もっと！」ボタンを出す（見本 17。押すと「もっとしりたい！」の画面＝13章）。「もっと！」が ないとき（「なぜ？」型）は、つぎに することが 1つなので、「ずかんに のこす！」を メインのボタン（青・大きい）で出す（#191）

## 13 条件変更（もしも）
- 変数をスライダーで動かし、アプリ側で再計算する
- 変化が一目で分かるようにする
  - スライダーに、もとの値の目印を残す（「もとは ○」「もとに もどす」）
  - 答えを大きく出し、「▲ もとの やく○ばい」「▼ もとの やく○ぶんの1」を添える
  - 「さっき」と「いま」の ぼうグラフをならべる
- 条件のといかけ（「じゃあ、40しゅるいだったら？」）をナビのふきだしに出す
- 「なぜ？」型は、変数がないので この画面は出ない。かわりに、なぞとき（12章）に「かんがえてみよう」のカードを出して、考えを ひろげる（答えを出す画面ではない）

## 14 アーカイブ（はてなずかん）
- 保存するもの：写真（切り抜きのみ）・問い・予想・結果・「どうだった？」（えらんだときだけ）
- 保存の前に「この はてな、どうだった？」を聞く（2026-11-13 に決めた。#164）。「おもしろい！」「ふつう」「むずかしい」の3つから1つ（顔は ナビの表情：にこにこ・ぽかん・ぎゅっ。押せる形で、もう一度 押すとえらびなおせる）。えらばなくても保存できる。答えは記録の `feeling`（`"fun" | "ok" | "hard"`）に入れ、ない記録（この機能より前のもの・えらばなかったもの）も そのまま読める。使いみちは、次の問いを作る手がかりだけ（17章）。グループの投稿には入れない・先生の管理画面には出さない（子どもの 感想なので、学校版でも出さない）
- 保存の前に「なかまにも みせる」で、入っているグループから見せるものを選べる（いくつでも。はじめは どれも選ばない。15章）。グループに入っていないときは出さない。保存すると「はてなゲット！」とスタンプを見せる。ずかんには のこせて、グループに見せられなかったときは「ずかんには のこせたけど、なかまには みせられなかったよ」と出す
- 「ずかんに のこそう！」の画面（#191。2026-11-14 に作り直した）
  - 見出し「ずかんに のこそう！」は、黄色い ふち文字（ink の ふちと 下に ずらした影。画面の はばに合わせて、1行に おさまる いちばん大きな文字。28〜40px）。前は 文字の 内がわを けずる ふちで、細くて 読みにくかった
  - つかまえた はてなを、1まいの カードにして 見せ場に置く：後ろで 光が 回り、カードが はずんで出て ふわふわ うき、ときどき 光が ななめに 走る。左上に ずかんの 何こめか（「3こめ」）の 丸い札（ずかんを 読みこめていないときは 出さない）
  - 上の段に「もどる」・ナビの ひとこと（「いい はてなだね！」）・「たすけて」（18章。出るときは、はばが たりないので ナビの ふきだしを はぶいて 顔だけにする）を 1行で ならべる
  - ならべる順：見出し → カード →「この はてな、どうだった？」（上の決まりのとおり。顔と ことばの 3つのボタンを 1行に）→「なかまにも みせる？」→「ずかんに のこす！」。390×844 で、入っている グループが 1つなら スクロールしなくても ぜんぶ 見える（カードの問題文は 3行まで）
  - 「なかまにも みせる？」は、うすいピンクの地（押せないので 線なし）の中に、見出しと グループごとの えらぶボタン（えらぶと 色がついて 押しこまれる）を ならべる（はばが たりれば 1行。グループが 多いときは 折り返す）。名前が出ないことの説明は そのまま出す
  - 「ずかんに のこす！」は、本のアイコンつきの メインのボタン。ときどき ぴょこっと はねる。ひくい画面（たかさ 830px まで）では 下に とめて、スクロールしなくても見えるようにする。解説が まだ できていないとき（12章。選んだ問いの解説を作る 2回目が、待ち・失敗のとき）は 押せない
  - のこしたら「はてなゲット！」（同じ ふち文字）。紙ふぶきが はじけ、カードが はずんで出て、新しいスタンプの まわりに 輪が 広がり、新しい称号と「ナビが そだったよ！」（19章）が ぽんっと出る（のこした しゅんかんだけ。あとで もどってきたときは 動かさない）
- 一覧：上の段は3分類のタブ（さんすう／りか／じょうほう。数つき）、下の段は単元のタブ（すべて・…。横にスクロール）。えらんだ分類で画面の地の色を うすく変える。保存した問い（切り抜き・問い・単元・日付・評価の札）。1つもないときは「まだ ないよ」
- 分類：算数・理科・情報の3分類の下を、さらに単元（面積・速さ・割合など）で分ける。仮の実装：単元のタブは AI が返す `topic` をそのまま使い、一覧は新しい順にならべる。詳細で「にている はてな」（同じ単元）を出す
- スタンプカードと称号は、スタンプの画面（`/stamp`）に出す（16章）
- 詳細でできること：答え合わせの見返し、解説、条件変更、出典の確認、関連する問い、なかまに みせるのを やめる（見せているグループの名前も出す）、けす（同じ問いへの再挑戦はなし）
- 削除：「えらんで けす」で個別・まとめて（「ぜんぶ えらぶ」）消せる。消す前に確認する
- 本人（プロフィール）しか読み書きできない（グループに見せたものを除く。15章）。学校版（未実装）で変更：授業時間中に保存したものは、担当クラスの先生も読める（`docs/06-school-expansion.md` 5.2）
- アカウントをけすときは、選択中だけでなく全プロフィールのずかんと、グループに見せた全投稿を消す（4.3）。投稿はずかんの `sharedGroups` の印ではなく、持ち主の記録から探す（印の保存に失敗した投稿も消すため）
- 保持期間：本人が削除するまで保持する。学校版（構想）で変更：学校のデータは、学校での利用が終わったら決めた期限内に消す（`docs/06-school-expansion.md` 9章）

## 17 問題の成長（MVP の Must）
- アプリでの学習の進み具合に応じて、出す問いを高度にしていく（同じシチュエーションを撮ったときに、以前より高度な問いが出るようにする）
- 学年は大まかな目安として使う（5章）。学年は、ことば・漢字・単位・計算の範囲を決める。問いの深さ（どこまで しくみに ふみこむか）は、下のレベルで決める（2026-11-13 に決めた。#174）
- 学習の進み具合の測り方（2026-11-06 に決め、2026-11-13 に見直した。#89・#174。`src/lib/progress.ts`）
  - 点数：自分で囲んで作った問い1つにつき1点。予想が「ピタリ」「おしい」のときは、もう1点（予想がよく当たる子は、少し早く難しくなる）
  - 経験のレベル：点数が 5・15・30・50 点になると、2・3・4・5 に上がる（上のレベルほど、たくさん遊ばないと上がらない。前の「5点ごとに1つ」では、10回ちょっとで いちばん上に とどいた）。点数は減らない
  - 手ごたえで上げ下げ：さいきんの記録（6件まで）の当たり（「ピタリ」「おしい」と、「なぜ？」型の正解）の割合が、6割以上なら経験のレベルより1つ上、2割以下なら1つ下にする（1〜5に おさめる）。記録が4件より少ないうちは動かさない（回数が少ないと ぶれが大きいため）。数の問いは、はずれて おどろくのが ふつうなので、下げるのは ほとんど当たらないときだけにする
  - 教科ごとのレベル：算数・理科・情報ごとに、その教科のさいきんの記録で、同じように上げ下げする（得意な教科は深く、にがてな教科は やさしく）。全体のレベルは、教科をまぜた さいきんの記録で決める
  - レベルは画面には出さない（下がったことが見えて、やる気を なくさないように）
  - ほかの人の問いで遊んだ分（グループの問いで遊ぶ機能。まだない）は、ずかん・スタンプには入れるが、点数には数えない（遊ぶだけでレベルが上がらないように）。記録の `origin` が `"played"` のもの
  - 出題済みの組み合わせには、遊んだ問いも入れる（同じ問いが出ないように）
- 「どうだった？」の反映（#164。`src/lib/progress.ts` の `feelingHints`）：ずかんの記録の `feeling` から、プロンプトに2つだけ足す。レベルの計算（点数・上げ下げ）には使わない
  - `liked`：「おもしろい！」だった問いの単元（`topic`）。新しい順に、同じ単元は1つにして、5つまで。あるときだけ「この子が『おもしろい！』と言った単元：…（にた切り口を1つ入れる）」と書く
  - `hardCount`：さいきん10問（ほかの人の問いで遊んだ分もふくむ記録の先頭10件）のうち「むずかしい」の数。1以上のときだけ書き、3以上で「1だんかい やさしくする」と添える。子どもが「むずかしい」を ためしに押しただけで 問いが ころころ変わらないよう、1〜2のときは数だけ伝える
  - どちらも、前の版のアプリは送らないので、なくてもよい
- 問いへの反映：全体のレベル・教科ごとのレベル（1〜5）と、そのめやす・挑戦した問いの数を、学年・出題済みの組み合わせといっしょにプロンプトへ渡す。どのレベルでも、そのもの自身への「なんで？」と意外性を最優先にする（`src/server/llm/prompts.ts`）
  - レベルのめやす（問いの深さ。問いの形に よらない）：1＝見て すぐ分かる ちがいの わけ／2＝はたらき（何のために あるか）／3＝しくみを1だんかいで説明できる／4＝しくみを2だんかいで説明する・ほかの ものとの共通点／5＝きまり・法則に つながる。数の問いでは、1＝考えかたが1つ、2＝2つの数の組み合わせ、3＝ふえかた・わりあい・単位の変換、4＝べき乗・場合の数、5＝しくみまで考える
  - 学年ごとの ことばと文の書きかた（#163）：1・2年は 1文20字まで・知っている ことばだけ（直径・表面・圧力 などは「まるい ふちの 長さ」のように言いかえる）／3・4年は 1文30字まで・習った ことばは使ってよい／5・6年は 習った漢字を ひらがなに ひらかず漢字で書き（選択肢・解説も）、「面積」「割合」「力」など教科の ことばを使う。わかち書きは どの学年も つづける（`src/server/llm/prompts.ts` の「学年に合わせる」）
  - 同じ ものを もう一度撮ったとき（出題済みに同じ target がある）は、前とは ちがう切り口で 1だんかい ふかい問いにするよう、AI に伝える（「学習の進み具合」の章）
  - 考えて、使わなかった案：分野の広がり（3分類のうち、いくつ遊んだか）で上げる（子どもに説明しにくいため）

## 18 先生に見える「いま」と たすけて（#192。2026-11-14 に決めた）
授業で使う先生が、「いま だれが アプリを使っているか」と「どこで止まっているか」を、画面共有なしで知るための機能。グループに入っている子だけが対象（グループの先生は、グループの管理者）。

- 子どもの画面が、入っているグループごとに、次のものを書く（`groups/{グループ}/presence/{uid}`。`docs/03-technical.md` 6章）
  - ログイン ID（メンバーの画面と同じ）・いまの画面（ホーム・撮影・囲む・問いを作っている（待ち）・はてなを選ぶ・予想・こたえあわせ・なぞとき・もしも・ずかんに のこす・ずかん・スタンプ・みんなの はてな・せってい など）・時刻・さいごのエラーの文（子ども向けの文から ふりがなを外したもの）と その時刻・たすけて（と その時刻）
  - **書かないもの**：写真・問いの中身・位置・ニックネーム
  - 書く回数：画面かエラーが変わったとき（つづけて変わっても 5秒に1回まで）と、さわっているあいだの 1分に1回（タブが見えていて、さわったときだけ。放っておくと書かない。同じ内容は書かない）。管理者（先生）のアカウントと、デモ（`/demo`）では書かない
  - ルールが本番に反映されていないなどで書きこみが断られたら、何も出さずに、その回は あきらめる（書きなおしをくりかえさない。子どもの画面は止めない）
- 「たすけて」ボタン：グループに入っている子にだけ出る（入っていない子・デモ・書きこみが断られているときは出ない）
  - 場所：画面の上のはし。もどる・タイトルと同じ段の右（`Page` のヘッダー・撮影の「とじる」の左・えらぶ画面のヘッダー）。ヘッダーがない下のナビの画面（ホーム・ずかん・スタンプ・みんな・せってい）は、右上に重ねる。こたえあわせ（ヘッダーがない）・ログインなどには出さない。撮る・囲む・ナビの操作とは かさならない
  - 押すと、presence に `help` と時刻が入り、「せんせいに しらせたよ」と出る（ボタンは「しらせたよ」の黄色になる）。もう一度 押すと とりけせる（「とりけしたよ」）。開きなおしても、押した状態は残る
  - 書きこみが断られたときは「とどかなかったよ。てを あげて せんせいを よんでね」と出す（押したのに知らせたことにしない）
- 子どもへの お知らせ：「グループの せんせいに、いま どの がめんを つかっているか みえるよ」を、はじめての登録の「じゅんび できたよ」（グループに入っているとき）・「せってい」・「グループに はいる」に出す（`PresenceNote`）
- 先生の画面（`/teacher/groups/{グループ}` の「きょう」。`docs/06-school-expansion.md` 5.2）：「いま使っている人」に、5分以内に動いた人の数と一覧（ログイン ID・いまの画面・さいごに動いた時刻・さいごのエラー・たすけて）を出す。「たすけて」の人は先頭で黄色にし、動かなくなってからも 30分までは残す。30秒ごとに読みなおす。人ごとの件数・当たり外れは出さない
- 退会（4.3）では、自分の presence も消す。メンバーを外すと、その人の presence も消す

## 19 ナビを育てる（#193。2026-11-14 に決めた）
続けて使いたくなるよう、ナビを育てる。ごほうびは「問いを見つけて ずかんに のこしたこと」に結びつけ、予想が当たったかどうかには結びつけない（予想をはずすことを楽しめるように）。`src/lib/navi.ts`
- ナビの元の画像（`public/navi/`）は変えない。成長の飾りと きせかえは、画像の上に重ねる SVG をコードで描く（`src/components/NaviDress.tsx`。画像の うしろに敷く物は、画像より前に出ないよう 後ろに置く）。ナビの7つの表情は そのまま使える。ふだんの ぷにぷにの動きは、画像と飾りを まとめて動かす
- 出す場所：ホームのナビ・ずかんに のこした直後の画面・スタンプの「きせかえ」。先生用の管理画面・グループの投稿・ナビの ふきだし（ほかの画面のナビ）には出さない
- 成長の段階（5つ。点数は 17章の学習の進み具合の点数 `progressPoints` をそのまま使う。点数は減らないので、段階も下がらない）

| 3 | げんきナビ | 8〜 | あたまに はっぱ |

- ずかんに のこした直後：その1つで段階が上がったときだけ、「ナビが そだったよ！」と新しい名前を出す（次に のこしたときは、また上がるまで出ない。ホームなどには出さない）
