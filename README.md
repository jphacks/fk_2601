# かこってはてな

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

## 製品概要
### 背景(製品開発のきっかけ、課題等）
いまは、わからないことを AI に聞けば、すぐに答えが返ってきます。便利な一方で、子どもが「自分で問いを立てて、考える」前に答えを受け取ることが増えています。理系（算数・理科・情報）への興味の入口は、答えを知ることではなく、「なんでだろう？」と自分で気づくことにあります。

身のまわりには、数や理科のふしぎがたくさんかくれています。信号が1日に青になる回数、ガチャを全種類そろえるまでの平均回数、氷がとけたときのコップの水の高さ、QR コードの白黒の並べ方の数。けれど、子どもが日常の景色の中でそれに気づく機会は多くありません。既存の画像検索・チャット AI・図鑑アプリは「答え」を出してくれますが、「問い」を見つけるのは人間の側の仕事のまま残っています。

私たちは、日本で理系に進む人が少ない原因のひとつを、小学生のうちに理系科目へ興味を持つ機会が少ないことだと考えました。そこで、AI を「答えを出すため」ではなく「問いを見つけるのを手伝うため」に使い、子どもが自分で「はてな」をつかまえる体験を作りました。

### 製品説明（具体的な製品の説明）
**かこってはてな**は、日常の風景から理系の「はてな（問い）」を見つける、小学生向けの Web アプリです。アプリをインストールする必要はなく、スマートフォンのブラウザで URL を開くだけで使えます。

- デモ：https://fk2601.vercel.app （「はじめて」でログイン ID とパスワードを決めると使えます。カメラが使えない場合は、ホームの「見本の絵」でも最後まで試せます）

体験の流れは次のとおりです（その場の体験は1〜3分で終わります）。

1. **撮る**：カメラで撮影するか、アルバムから写真を選びます。
2. **囲む**：写真の気になる部分を、指でぐるっと囲みます（自由な投げ縄）。囲まないと問いは出ません。
3. **はてなを選ぶ**：囲んだ部分から、AI が「予想がはずれて、おどろく」問いを3つ作ります。3つから選ぶか、自分で問いを書くこともできます。
4. **せーの！（予想）**：答えを見せる前に、必ず子ども自身が予想します。学年に合わせて、4年生までは5つの範囲から選び、5年生からはスライダーや数の入力で答えます。
5. **しょうたい（答え合わせ）**：答えと予想のズレを、数直線・倍率（「予想の約7倍！」）・身近なものへの言いかえで見せます。ズレの大きさで「ピタリ（誤差5%以内）／おしい（2倍以内）／大はずれ」を判定し、ナビ（キャラクター）の表情とはんこが変わります。
6. **なぞとき（解説）**：ナビが、答えまでの考えかたを手順で説明します。出典・もとにした数も見られます。
7. **もしも**：条件（数・大きさなど）をスライダーで変えて、答えがどう変わるかを、その場で確かめられます。
8. **ずかんに のこす**：写真（切り抜き）・問い・予想・結果を「はてなずかん」に保存します。分類（さんすう・りか・じょうほう）ごとにスタンプが集まり、集めると称号がもらえます。「みんなにも みせる」を選ぶと、切り抜き画像・問い・称号だけを、名前を出さずに公開できます。

### 特長
#### 1. 問いを見つけるのは、子ども自身
写真を自分で「囲む」操作をしないと、問いは出ません。どこに注目するかを子どもが決めるので、受け身の学びになりません。さらに、答えを見せる前に必ず予想してもらい、「予想がはずれたおどろき」を学びの入口にします。AI には、「多くの子どもの予想が正解から5倍以上ずれる問い」や「思いこみがひっくり返る問い」だけを作らせ、数えるだけ・かけ算1回で出る「ただの計算」の問いは作らせません（例：ガチャ10種類をぜんぶそろえる平均は約29回／氷がとけてもコップの水の高さは変わらない）。

#### 2. 答えは AI に計算させず、コードで計算して確かめる
AI は計算をまちがえることがあり、子どもがまちがった答えを覚えてしまうおそれがあります。そこで AI には「式」と「変数」だけを出させ、答えはアプリ（math.js）が計算します。AI 自身が考えた答えと、式から計算した答えが5%以上ずれる問いは、出しません。「もしも」で条件を変えたときの再計算も、同じ式をアプリ側で解くので、AI を呼ばずに一瞬で動きます。

#### 3. 子どもが使う前提の、学年への適応と安全
学年に合わせて、漢字・ふりがな・単位・予想の入力方法・解説の計算を切り替えます（22px 以上の漢字にはふりがな、小さい文字はひらがな、むずかしい言葉はやさしい言葉に言いかえ）。学習の進み具合に合わせて、問いも少しずつむずかしくなります。安全面では、起動時と撮影時に「人の顔はとらないでね」「まわりに気をつけてね」を表示し、AI に送るのは囲んだ部分の切り抜きだけ（外側は白で塗りつぶし、位置情報などの情報を消して縮小）、危険な行動をすすめる問いは出さないよう AI に制約をかけています。公開する情報も、切り抜き画像・問い・称号に限り、ユーザー名と位置情報は含めません。

### 解決出来ること
- 子どもが、いつもの景色の中に算数・理科・情報のふしぎがあることに気づけます。「これも数学と結びつくのか！」という発見が、理系への興味の入口になります。
- 答えをもらう前に「予想する」ことで、自分で考える習慣と、直感がはずれたときの「なんで？」という好奇心が育ちます。
- 保護者や先生は、端末を貸すだけで使えます。学年や進み具合に合わせた問いが自動で出るので、教える側の準備は要りません。散歩・お出かけ・授業・自由研究など、場所を選ばず使えます。

### 今後の展望
- **はてなマップ**：つかまえた場所を地図で見返せるようにします（位置は自分のずかんだけで使い、公開には含めません）。
- **学習の進み具合の改善**：いまは挑戦した数からレベルを決めていますが、正答の傾向なども使って、一人ひとりに合う難しさにします。
- **安全の強化**：画像と生成文のチェック（モデレーション）、送信前に他人の顔を自動でぼかす機能、不適切な投稿を消す手段（通報など）を入れ、匿名公開を安心して広げられるようにします。
- **使う場面を広げる**：兄弟で1台を使うためのプロフィールの切りかえ、「別のもので試す」（同じ考えかたの別の問いを AI が出す）、学校の授業や自由研究での利用を進めます。

### 注力したこと（こだわり等）
* **「答え」ではなく「問い」を出す体験の設計**：囲む → 予想 → ズレ → なぞとき → もしも という、1〜3分の流れを作り込みました。「予想がはずれるおどろき」が出るよう、AI へのプロンプトを何度も実際の AI で試して書き直しました（数えるだけの問いや、答えが問題文に書いてある問いを出させない指示と、よい例・悪い例を入れています）。
* **答えの正しさ**：AI に計算させず、式をコードで計算して検算する仕組みにしました。確率・場合の数（ガチャの平均回数・誕生日の確率など）の式も、安全に計算できるようにしています。
* **小学生が読めること**：ふりがなの記法を決め、大きい文字にはふりがな、小さい文字はひらがなに自動で直します。熟語を1字ずつ読んで「前提」が「まえてい」になるような変な読みを防ぐため、AI に熟語ごとにふりがなをつけさせ、むずかしい言葉をやさしい言葉に言いかえさせています。
* **変化が目で見えること**：答えの数がふえる動き、予想の位置から答えの位置へ旗が動く数直線、条件を変えたときの「もとの約○倍」と「さっき／いま」のぼうグラフなど、ズレと変化が一目でわかるようにしました。見た目は、デザイン見本（色・形・ナビの7つの表情）を決めて、全画面でそろえています。
* **動作の確実さ**：本物の Claude・Firebase で、撮影から保存までを通して確かめました。AI が使えないときや会場で撮影できないときでも、見本の絵（ガチャ・信号・氷のコップ）で最後まで体験できます（AI を呼ばずに見本の問いに切りかわります）。本番環境でログインの確認が動かなくなる不具合も、ログのエラーから原因を特定し、ライブラリを使わない確認に作り直して解決しました。
* **コストと速さの検討**：Opus・Sonnet・Haiku を同じ写真で比べて、待ち時間と費用を実測しました（Sonnet 5.5・考える深さ low で、約13〜20秒、1回およそ3セント）。待ち時間は、ナビの「まめちしき」でつなぎます。

## 開発技術
### 活用した技術
#### API・データ
* Claude API（Anthropic Messages API。画像入力と、Zod で定義した形の構造化出力（JSON）。本番は Claude Sonnet 5.5、環境変数で Opus 5.5・Haiku 5.5 にも切りかえ可能）
* Firebase Authentication（ユーザー名とパスワードでのログイン。ユーザー名を英数字に変換してメール形式で登録するので、メールアドレスは集めません）
* Cloud Firestore（プロフィール・はてなずかん・匿名公開の保存。セキュリティルールで、本人だけが読み書きできるようにしています）
* Google の ID トークン用の公開鍵（securetoken の X.509 証明書）：ログインした人だけが AI を呼べるよう、サーバー側でトークンを確認するために使用
* Google Fonts（Mochiy Pop One・Zen Maru Gothic。`next/font` で配信）
* ブラウザの標準 API（getUserMedia によるカメラ、Pointer Events と Canvas による投げ縄と切り抜き）

#### フレームワーク・ライブラリ・モジュール
* Next.js 16（App Router）・React 19・TypeScript 5.9
* Tailwind CSS 4（デザイン見本の色・影・角丸を、テーマとして定義）
* math.js 15（AI が出した式を、eval を使わずに安全に計算。使える名前を限定し、危険な関数は無効化）
* Zod 4（AI の出力の形の定義と検証）
* @anthropic-ai/sdk、Firebase JavaScript SDK 13
* Vercel（公開。関数は東京リージョン）

#### デバイス
* スマートフォン（iOS Safari・Android Chrome の最新版）：カメラでの撮影、指での投げ縄の操作
* パソコンのブラウザでも動作（カメラが使えない場合は、アルバムの写真か、見本の絵で試せます）

### 独自技術
#### ハッカソンで開発した独自機能・技術
* **囲んだ部分だけを切り抜いて AI に送る仕組み**：指で囲んだ線から、外側を白で塗りつぶした切り抜きを作り、写真の向き（EXIF）を直したうえで長辺 1024px の JPEG に描き直します（位置情報などは残りません）。Firestore の1件の上限に収まるよう、品質も自動で調整します。
  * [`src/components/LassoPicker.tsx`](src/components/LassoPicker.tsx)（commit `e9e16d7`）、[`src/lib/image.ts`](src/lib/image.ts)（commit `a2a5d92`）
* **「予想がはずれて、おどろく」問いを作るプロンプト**：意外性を最優先にし、数えるだけの問いなどを禁止し、学年別の単位・計算、言いかえの決まり、よい例と悪い例、危険な内容の制約を入れています。
  * [`src/server/llm/prompts.ts`](src/server/llm/prompts.ts)（commit `7ddb614`、熟語ごとのふりがなと言いかえは commit `1d443d3`）
* **AI の式を安全に計算し、検算して、合わない問いを出さない仕組み**：使える名前を限定し、危険な関数を無効化した math.js で式を計算します。確率・場合の数の関数（ガチャの平均回数・組み合わせ・誕生日の確率）を追加し、条件を動かしたときの答えの範囲も計算します。AI の答えとの差が5%を超える問いは出しません。
  * [`src/lib/calc.ts`](src/lib/calc.ts)（commit `3b2e4e7`、確率・場合の数の関数は commit `4dd9094`）、[`src/server/llm/validate.ts`](src/server/llm/validate.ts)（commit `d1c6cd3`）
* **予想とのズレと、条件を変えたときの変化の見せ方**：ふつうの目盛りで、ズレがそのまま長さに出る数直線（旗が予想から答えへ動く）、答えの数がふえる動き、ピタリ／おしい／大はずれの判定とはんこ、「もしも」のスライダーとぼうグラフ。
  * [`src/components/NumberLine.tsx`](src/components/NumberLine.tsx)（commit `d81fea9`）、[`src/components/ConditionSliders.tsx`](src/components/ConditionSliders.tsx)（commit `1b72f7b`）、[`src/components/ResultSummary.tsx`](src/components/ResultSummary.tsx)（commit `184c8e7`）
* **ふりがなの記法と、小さい文字のひらがな化**：AI に `{漢字|よみ}` の短い記法で書かせ、大きい文字では `<ruby>` に、小さい文字では読みに置きかえます（それ以外のタグは文字として表示するので、AI の出力が HTML として実行されません）。答えの単位（回・日分 など）の読みも、アプリで付けます。
  * [`src/lib/ruby.ts`](src/lib/ruby.ts)（commit `3b2e4e7`、記法の追加は commit `c53bcd0`）
* **ライブラリを使わない ID トークンの確認**：ログインした人だけが AI を呼べるよう、Google の公開鍵で、署名（RS256）・有効期限・発行元・対象・利用者を、Node 標準の暗号機能だけで確認します。本番で `firebase-admin` が読み込めない不具合を、これに置きかえて解決しました。テスト用の鍵で、改ざん・期限切れ・別プロジェクト宛て・`alg=none` などを断ることを確かめています。
  * [`src/server/auth.ts`](src/server/auth.ts)（commit `9b29201`）
* **AI が使えなくても最後まで体験できる見本の絵と見本の問い**：ガチャ・信号・氷のコップの絵をブラウザ内で描き、AI がつながらないときは、本物と同じ形の見本の問い（意外性のあるもの）に切りかえます。
  * [`src/lib/scenes.ts`](src/lib/scenes.ts)（commit `352337d`）、[`src/server/llm/builtin.ts`](src/server/llm/builtin.ts)（commit `1f59dd4`）
